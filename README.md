# SocialApp Backend

API backend para una red social con autenticación, amistades, publicaciones y comentarios.

---

## Tecnologías

- Node.js  
- Express (framework web)  
- MySQL (base de datos)  
- JSON Web Token (autenticación)  
- bcrypt (hash de contraseñas)  

---

## Funcionalidades

- Autenticación de usuarios (registro / login)  
- Gestión de usuarios  
- Sistema de amistades  
- Creación y gestión de publicaciones  
- Comentarios en publicaciones  

---

## Estructura del Proyecto

Arquitectura basada en funcionalidades (feature-based). Cada feature contiene controllers, services, rutas y middleware.
